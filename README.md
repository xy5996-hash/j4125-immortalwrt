# ImmortalWrt J4125-4L Router

This repository builds a deliberately small ImmortalWrt x86_64 firmware profile for one fixed device:

- CncTion J4125-4L
- Intel Celeron J4125
- 4 GiB RAM
- 4x Intel I226-V using the `igc` driver
- bare-metal UEFI only
- squashfs combined EFI image

## Phase 1

Implemented:

- high-level YAML profile
- deterministic YAML to `.config` renderer
- pinned ImmortalWrt, feed, iStore, OpenClash, mihomo, and setup-wizard versions
- `feeds.conf.lock`
- hardware profile, forbidden-package, manifest, and secret checks
- setup wizard (luci-app-netwizard)\n- console shortcut menu\n- validation GitHub Actions workflow

Not implemented yet:

- full firmware build
- GitHub Release workflow
- `mihomo-core` package
- runtime subscription or credential configuration

The only human-maintained profile is `config/j4125-router.yaml`. The file under `config/generated/` is generated by `scripts/render-config.py` and must not be edited manually.

## Local validation

```bash
python3 -m pip install -r requirements.txt
bash scripts/validate-config.sh
```

This does not clone ImmortalWrt, download package sources, or run a firmware build.
